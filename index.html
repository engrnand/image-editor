Working…

Magic select

Click on the object. A flood fill runs on an edge-preserving copy of the image to find the region, then GrabCut snaps the border to the real edge.

Object box

Drag a box that fully contains the object with a little background around it. GrabCut separates foreground from background inside it.

Rectangle marquee

Drag a plain rectangle. Shift adds to the selection, Alt subtracts.

Freehand lasso

Draw around the object and release to close the path. Shift adds, Alt subtracts.

Refine brush

Paint to add to the selection, hold Alt to subtract. The ring on the canvas is the real brush size — zoom in for fine edge work. [ and ] resize it.

Move & transform

Drag inside a selection to lift it onto its own layer and move it — the hole behind it is filled automatically. Alt-drag copies instead, leaving the original.

Click a layer to select it, drag to move, corner handles scale, the top handle rotates. Delete removes the active layer.

Clone stamp

Alt+click sets the source point, then drag to paint pixels from there. The manual fallback for when the automatic fill smudges.
